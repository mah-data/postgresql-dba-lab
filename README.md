# PostgreSQL DBA Lab

A practical PostgreSQL Database Administration project that demonstrates installation, configuration, administration, backup, recovery, monitoring, maintenance, performance tuning, and high availability techniques.

## Objectives

* Install PostgreSQL on Windows and Linux
* Configure PostgreSQL for production environments
* Manage databases, users, roles, and permissions
* Perform backup and recovery operations
* Monitor database health and performance
* Optimize SQL queries and indexes
* Implement routine maintenance tasks
* Configure replication and high availability
* Document best practices and troubleshooting procedures
